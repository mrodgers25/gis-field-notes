**Dates:** each item starts with a date tag like `2026-08` = when I actually worked on it. Notes use that date, not the day they're published: name the file `notes/<YYYY-MM>-short-slug.md`, put `*Worked on: <Month YYYY>*` under the title, and show it in the README index "When" column (newest first).

The fix: validate payload keys against the layer schema before calling edit_features.

- [x] `2026-08` **Reuse coordinates in a migration with an address hash.** Hash normalized addresses to match records against an old layer and reuse existing coordinates. About 90% of records needed no re-geocoding, which saved credits and time.
